{{/* Bookkit Research: load the R19 dossier for a chapter at build time. Input: dict {"page": Page, "book": ..., "chapter": ...}. The data root comes from Bookkit research configuration (default "content/research/chapters"), so consuming sites only supply files. Returns: dict {"dossier": dict|nil, "expected": bool}. "expected" is true only when the book's dossier directory already holds dossiers but this chapter file is absent (research in progress for this book with a gap). Books with no dossiers at all stay quiet: absence there means "not in the programme", not "publishing defect". The caller warns only when configured to (warnMissingDossier, default false). Missing dossiers never break chapter rendering and nothing is fabricated. */}} {{- $found := dict -}} {{- $expected := false -}} {{- $cfg := partial "bookkit/research/config.html" .page -}} {{- $path := printf "%s/%s/%s.yaml" $cfg.dataRoot .book .chapter -}} {{- if fileExists $path -}} {{- with readFile $path -}} {{- with transform.Unmarshal . -}} {{- $found = . -}} {{- end -}} {{- end -}} {{- else -}} {{- $bookDir := printf "%s/%s" $cfg.dataRoot .book -}} {{- if fileExists $bookDir -}} {{- range readDir $bookDir -}} {{- if strings.HasSuffix .Name ".yaml" -}} {{- $expected = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return dict "dossier" $found "expected" $expected -}}
